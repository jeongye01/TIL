## 핵심 요약

- `map()`은 즉시 결과를 생성하지 않는다.
- 반환값은 `map` 객체(이터레이터)이다.
- 값은 실제로 필요할 때 하나씩 계산된다. 이를 지연 평가라고 한다.

---

## 기본 동작

```python
arr = ["1","2","3"]
m =map(int, arr)

print(m)

```

출력:

```
<map object at 0x...>

```

위 출력은 실제 값이 아니라 `map` 객체의 주소 표현이다. 이 시점에서는 변환이 아직 수행되지 않았다.

---

## 지연 평가란?

지연 평가는 값을 미리 계산하지 않고, 실제로 사용되는 시점에 계산하는 방식이다.

```python
m =map(int, ["1","2","3"])

print(next(m))# 1
print(next(m))# 2
print(next(m))# 3

```

- `next()`가 호출되는 순간에만 `int()` 함수가 실행된다.
- 불필요한 계산을 줄일 수 있다.
- 메모리 사용량이 적다.

---

## 이터레이터의 특징

```python
m =map(int, ["1","2","3"])

print(list(m))# [1, 2, 3]
print(list(m))# []

```

- `map` 객체는 이터레이터이기 때문에 한 번만 순회할 수 있다.
- 한 번 소비된 이후에는 다시 사용할 수 없다.

---

## 실제 값을 사용하려면

```python
nums =list(map(int, ["1","2","3"]))

```

이 시점에서 모든 값이 계산되고 리스트로 저장된다.

---

## map과 리스트 컴프리헨션 비교

| 항목 | map | 리스트 컴프리헨션 |
| --- | --- | --- |
| 평가 방식 | 지연 평가 | 즉시 평가 |
| 반환 타입 | iterator | list |


---

## 언제 map을 사용하는가

권장되는 경우

- `input().split()` 결과를 바로 변환할 때
- 한 번만 순회하면 되는 데이터
- 대용량 데이터 스트리밍 처리

권장되지 않는 경우

- 인덱싱이 필요한 경우
- 여러 번 순회해야 하는 경우
- 복잡한 조건 로직이 필요한 경우
